# Установка LocalPDF Desk на Windows

## Скачать

Перейдите в [GitHub Releases](https://github.com/DrowzyX/LocalPDFDesk/releases) и выберите файл **LocalPDFDesk-1.3-cryptopro.exe** (когда он появится в релизе).

Это портативный Windows EXE. Скачайте его в любую папку и запустите двойным щелчком. Для просмотра и обычного редактирования PDF интернет не нужен.

> Windows 10/11 x64. Сборка предварительная: полноценное испытание на Windows и с реальным токеном не завершено.

### Электронная подпись

Для подписи ГОСТ дополнительно должны быть установлены и настроены **КриптоПро CSP**, CAdESCOM и драйверы Рутокена. Сертификат должен быть доступен в личном хранилище Windows вместе с закрытым ключом. Функция экспериментальная: проверяйте подписанные PDF независимым валидатором, особенно перед официальной отправкой. Внешний вид плашки сам по себе не означает наличия действительной подписи.

### Если Windows показывает предупреждение

Убедитесь, что файл получен из официального GitHub-репозитория и совпадает с контрольной суммой SHA-256 релиза. Не отключайте антивирус ради запуска. На корпоративных ПК уточните разрешение у администратора.

### Как печатать и менять масштаб

- `Ctrl+P` — печать.
- `Ctrl + колесо мыши` — увеличение/уменьшение.
- `Ctrl+O` — открыть PDF.
- `Ctrl+S` — сохранить копию.
- «Целая страница» — подгонка PDF под размер окна.
