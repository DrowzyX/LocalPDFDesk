# Установка LocalPDF Desk на Astra Linux

**Статус: тестовый пакет исходников, не автономный установщик.** Проверка на конкретных версиях Astra Linux SE 1.7/1.8 пока не выполнена; возможна несовместимость системного Python или библиотек.

## 1. Как скачать

Перейдите на [страницу релизов](https://github.com/DrowzyX/LocalPDFDesk/releases), когда релиз будет опубликован, и выберите:

- `localpdf-desk_1.3-1_all.deb` — тестовый пакет и ярлык программы.
- `LocalPDFDesk-linux-1.3.tar.gz` — универсальный архив для ручного запуска.

Если файлы не опубликованы в разделе Releases, они пока доступны только в комплекте, переданном автору проекта; не считайте кнопку на GitHub действующей загрузкой.

## 2. Проверьте систему

Откройте терминал:

```bash
cat /etc/os-release
python3 --version
uname -m
```

**Для текущего набора библиотек необходим Python 3.10 или новее.** PyMuPDF 1.26.6 не поддерживает Python 3.9 и ниже. Не подменяйте системный Python ради приложения: используйте отдельный совместимый Python, установленный администратором. Если его нет, установка может завершиться ошибкой.

## 3. Установите системные компоненты

При наличии настроенного доверенного репозитория ОС:

```bash
sudo apt update
sudo apt install python3-venv python3-tk
```

Для OCR можно дополнительно установить Tesseract и языковые данные, если они доступны в репозитории:

```bash
sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-eng
```

На рабочих станциях с ограниченной политикой безопасности предварительно согласуйте установку пакетов.

## 4. Установите DEB

В папке с загруженным файлом:

```bash
sudo apt install ./localpdf-desk_1.3-1_all.deb
```

Пакет разместит программу в `/opt/localpdf-desk` и добавит ярлык, но **не содержит PyMuPDF/Pillow**. Создайте зависимости в домашнем каталоге, без `sudo`:

```bash
mkdir -p ~/.local/share/localpdf-desk
python3 -m venv ~/.local/share/localpdf-desk/venv
~/.local/share/localpdf-desk/venv/bin/python -m pip install -r /opt/localpdf-desk/requirements.txt
```

Для систем с Python 3.9 или ниже используйте отдельно установленную совместимую версию Python при создании среды. Для компьютеров без интернета заранее перенесите подходящие wheel-пакеты и используйте `--no-index --find-links /путь/к/wheelhouse`.

Запуск:

```bash
localpdf-desk
```

Или выберите программу в меню приложений.

## 5. Если что-то не работает

- `No matching distribution found for PyMuPDF` — несовместимая версия Python/архитектура/glibc либо отсутствует доступ к пакету.
- `No module named tkinter` — нужен системный пакет `python3-tk` для используемой версии Python.
- `No module named pymupdf / fitz / PIL` — Python-зависимости установлены не в ту среду.
- Не открывается графическое окно — проверьте активную графическую сессию X11/Wayland, переменную `DISPLAY` и запуск из пользовательской сессии.
- Нет OCR — проверьте наличие Tesseract и языковых моделей.

## 6. Ограничения

Функции ЭП через Windows CAdESCOM и сканирование WIA **на Astra Linux не работают**. Поддержка КриптоПро Linux и SANE требует отдельной реализации. Внедрение в сертифицированную/изолированную среду требует согласования и проверки ПО администраторами.
