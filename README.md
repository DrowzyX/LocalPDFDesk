# LocalPDF Desk

**LocalPDF Desk** — бесплатный офлайн-просмотрщик и редактор PDF для Windows и Linux.

![version](https://img.shields.io/badge/version-1.3_preview-orange) ![platform](https://img.shields.io/badge/platform-Windows%20%7C%20Linux-blue) ![license](https://img.shields.io/badge/license-AGPL--3.0-green)

> **Предварительная версия.** Совместимость со всеми Linux-дистрибутивами и подписание с настоящим Рутокеном пока не подтверждены.

## Возможности

- Просмотр PDF, печать, автоматическая подгонка страницы и масштабирование `Ctrl + колесо мыши`.
- Добавление, перемещение и редактирование текста, выбор шрифтов.
- Добавление, удаление, объединение, обрезка и поворот страниц.
- Сжатие PDF с сохранением текста или пересборкой сканов как JPEG + OCR.
- Распознавание русского и английского текста (офлайн, при наличии моделей).
- Извлечение изображений, фильтры с предварительным просмотром.
- Графическая подпись и удаление стандартных метаданных PDF.
- Сканирование через WIA в Windows.
- Экспериментальная электронная подпись через КриптоПро CSP / CAdESCOM и совместимые токены Рутокен в Windows.

## Платформы

| Платформа | Статус |
|---|---|
| Windows 10/11 x64 | Тестовый EXE |
| Astra Linux, ALT Linux, РЕД ОС | Планируются и требуют проверки на реальных системах |
| Debian, Ubuntu | Тестовая Linux-версия с Python/Tk |
| Fedora, Rocky, CentOS Stream | Запуск из исходников; совместимость не подтверждена |

**Важно:** КриптоПро-подпись на Linux не реализована. Для неё потребуется отдельная интеграция с Linux CSP.

## Запуск из исходников

Требуется Python 3, Tkinter и библиотеки из `requirements.txt`.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Для Linux отдельно могут требоваться системные пакеты Tk и Tesseract с русским/английским языками.

## Важные замечания

- Видимый штамп электронной подписи сам по себе не подтверждает подписание PDF.
- Криптографическую корректность и доверие к сертификату необходимо проверять независимо.
- Для официального документооборота используйте только проверенную конфигурацию КриптоПро и совместимый PDF-валидатор.
- Никогда не прикладывайте к Issues закрытые ключи, PIN-коды или конфиденциальные документы.
