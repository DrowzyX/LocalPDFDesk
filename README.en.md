# LocalPDF Desk

Offline, open-source-oriented PDF viewer and editor for Windows and Linux.

**Status: experimental preview.** Release v1.3.0 packages are available for download. The complete source tree has not yet been uploaded to the repository.

| Platform | Download |
|---|---|
| Windows 10/11 x64 | [Download Windows ZIP](https://github.com/DrowzyX/LocalPDFDesk/releases/download/v1.3.0/LocalPDFDesk-Windows-v1.3.zip) |
| Astra Linux (experimental) | [Download Astra ZIP](https://github.com/DrowzyX/LocalPDFDesk/releases/download/v1.3.0/LocalPDFDesk-AstraLinux-v1.3-preview.zip) |
| Other Linux (source archive) | [Download Linux ZIP](https://github.com/DrowzyX/LocalPDFDesk/releases/download/v1.3.0/LocalPDFDesk-Linux-Other-v1.3-preview.zip) |

[Release details](https://github.com/DrowzyX/LocalPDFDesk/releases/tag/v1.3.0). All packages above are ZIP archives. Unpack before installing or running.

Features include PDF viewing, text editing, page rotation/cropping/merging, compression, offline OCR, image extraction, filters, and printing. Windows-only experimental features include WIA scanning and PDF signing using installed CryptoPro CSP/CAdESCOM with compatible Rutoken devices.

**Limitations:** Linux compatibility across Astra Linux, ALT Linux, RED OS and other distributions is unverified. Linux CryptoPro signing is not implemented. Digital signatures must be independently validated before use in official workflows.
